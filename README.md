# Senate Probability Desk

A static, map-first prototype for a daily automated U.S. Senate forecast.

## Run

Open `index.html` in a browser. The state-shape map uses D3, TopoJSON, and `us-atlas` from public CDNs, so the map needs internet access. If those files do not load, the site shows a race-link fallback.

The browser model rolls to a new daily run on the first page load after 6:00 AM Central. A production deployment should add a scheduled build job before that time to refresh polling, finance, primary, and candidate data files.

## Site structure

- `index.html`: headline control forecast, state-shape map, and key charts.
- `races.html`: map-first race browser.
- `race.html?state=MI`: individual race detail page. Change the `state` query value to any 2026 Senate state.
- `methodology.html`: model explanation.
- `sources.html`: public-source plan and links.

## Data plan

Use:

- VoteHub Polling API for available polling, generic ballot, and approval data.
- OpenFEC for campaign finance and candidate filings.
- MIT Election Lab for historical returns and backtesting.
- Census API for state-level demographic context.
- civicAPI for live election results where available.
- `us-atlas` for public state geometry.
- A manual ratings/news ledger for Cook, Sabato, Inside Elections, Split Ticket, CNalysis, retirements, endorsements, scandals, and ballot access.
- A primary/control ledger for unresolved primaries, runoffs, Democratic withdrawals, independent candidates, and likely Democrat/Republican organizing alignment.
- A candidate ledger for already-held primaries. Current examples include Cooper/Whatley in North Carolina, Brown/Husted in Ohio, Talarico plus the Cornyn/Paxton runoff in Texas, Stratton/Tracy in Illinois, Cotton/Shoffner in Arkansas, Hyde-Smith/Colom in Mississippi, Capito/Anderson in West Virginia, and Ricketts/Osborn in Nebraska.

Do not use FiveThirtyEight as a live polling source. 538 was shut down; archived data can be useful only for historical comparison/backtesting.

## Model status

The current probabilities are prototype outputs generated by a browser-side Monte Carlo model. It now includes ratings, fundamentals, polling placeholders, finance/candidate signals, primary uncertainty, independent handling, correlated national/regional/race error, and simulated tipping-power rankings. It is still not publication-grade until real daily adapters and backtests are added.

Probability history starts from the first day a browser opens the page and is stored locally in `localStorage`; it is not backfilled with fake historical points.
