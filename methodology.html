Model layers

  • State fundamentals State lean, recent Senate performance, incumbency, candidate quality, finance, and approval/national climate.
  • Primary layer Unresolved primaries and runoffs widen the error band. Resolved primaries shrink candidate uncertainty.
  • Independent layer Independent candidates are colored purple and credited as Democrat or Republican for control based on the most likely organizing arrangement, with a discount when that path is uncertain.
  • Polling layer VoteHub or another public/licensed poll feed should supply race polls, generic ballot, and approval. FiveThirtyEight is not treated as a live polling source because it shut down.
  • Ratings layer Cook/Sabato/Inside/Split Ticket/CNalysis should be entered through a transparent manual file unless legitimate API access exists.
  • Simulation layer Each run includes national error, turnout miss, regional error, race-level miss, primary shock, and independent-candidate shock.
  • Tipping power Most decisive races are counted from simulations where that exact seat changes chamber control, not merely from closeness.
  • Daily update GitHub Actions runs the generator each morning, commits `data/forecast.json`, and keeps the public site on one shared forecast until the next run.
  • Backtesting MIT Election Lab returns should be used to tune error and fundamentals before public launch.
