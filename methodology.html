Short version

  • Polling VoteHub generic-ballot polls are averaged with recency, sample-size, population, internal/partisan, and repeated-pollster weights.
  • Fundamentals The baseline blends race ratings, state lean, recent Senate results, incumbency, candidate quality, finance, and population growth.
  • Uncertainty Simulations include national error, regional error, turnout miss, race error, primary uncertainty, and independent-candidate uncertainty.
  • Control math Independent candidates are counted by likely caucus for chamber control. Tipping power comes from simulations where that exact race changes control.
  • Publishing GitHub Actions runs the generator daily and writes one shared `data/forecast.json` file for everyone.
