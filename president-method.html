Method.

Monte Carlo simulation with candidate-specific modifiers and correlated polling error.

Model Overview
Simulations
100,000 Monte Carlo trials per forecast

50 states + District of Columbia (538 total electoral votes)
Win threshold
270 electoral votes
Error correlation
0.6 between states (national polling error affects all states)
Key Features
Candidate modifiers
Home-state, regional, ideological, favorability, and electability adjustments
Correlated error
National polling error correlated across states
Tipping point
State most likely to decide the election
Popular vote
Weighted by state population

Candidate Modifiers

The model adjusts state margins based on candidate characteristics:

  • Home-state modifier: +4 margin boost in candidate's home state
  • Regional modifier: +1.5 margin boost in states in candidate's region (Northeast, South, Midwest, West, Plains)
  • Ideological modifier: Adjusts based on state partisan lean vs candidate ideology (progressive/moderate/conservative)
  • Favorability modifier: Scales state margins by candidate favorability relative to baseline
  • Electability modifier: Adjusts error terms based on candidate electability score

State Baselines

Each state has a baseline margin based on 2024 presidential results:

  • Partisan baseline: 2024 Democratic margin (positive = Dem advantage, negative = Rep advantage)
  • Electoral votes: State's EV count
  • Region: Geographic region for regional modifier calculations
  • Population: State population for popular vote weighting

Correlated Polling Error

The model generates correlated polling error across states:

  • National error: Drawn from normal distribution (SD = 3.5 points)
  • State-specific error: Drawn from normal distribution (SD = 4.0 points)
  • Correlation: 0.6 (60% of state error comes from national component)
  • This accounts for systematic polling bias that affects all states similarly

Monte Carlo Simulation

For each of 100,000 simulations:

  1. Generate correlated polling error for all states
  2. Calculate final margin for each state (baseline + modifiers + error)
  3. Determine state winner based on margin
  4. Sum electoral votes for each candidate
  5. Track state wins, EV distribution, and popular vote

Final probabilities are calculated as the proportion of simulations each candidate wins.

Tipping Point State

The tipping point state is the state most likely to decide the election:

  • Calculated as the state with the highest "tipping power"
  • Tipping power = min(Dem wins, Rep wins) × state EV
  • States that are close to 50% probability with high EV have highest tipping power

Historical Backtesting

The model is validated against historical presidential elections:

  • 2020: Biden vs Trump (306-232 EV)
  • 2016: Clinton vs Trump (227-304 EV)
  • Additional cycles (2012, 2008, 2004) can be added

Backtest metrics include:

  • Mean Brier score (lower is better)
  • Overall accuracy
  • Calibration by probability bucket (50-60%, 60-70%, etc.)

Fundamentals

The model incorporates national fundamentals from real-time data sources:

  • Generic ballot: Fetched from Pollfinity API (same as Senate model) to measure national partisan mood. Currently shows D+5.
  • Presidential approval: Fetched from Pollfinity API for Trump approval rating. Currently shows 47% approval.
  • Economic indicators: Using current approximate values (unemployment 4.0%, GDP growth 2.0%). These would be updated with real-time data when available.
  • State polling: Fetched from RealClearPolling for state-specific presidential polls.

These fundamentals are applied as a national shift that affects all states proportionally. State-specific polling is blended with baseline margins (40% polling weight, 60% baseline weight).

Note: For the 2028 presidential cycle, early polling is limited. The model uses current 2026 conditions and Trump approval as reasonable proxies, which will be updated as more 2028-specific data becomes available.

Data Sources

The model uses the following data sources:

  • RealClearPolling: Presidential polling data by state and nationally
  • Pollfinity API: Generic ballot and Trump approval ratings (same as Senate model)
  • Economic indicators: Current economic conditions (unemployment, GDP growth)

For the 2028 presidential cycle, early polling is limited. The model uses current 2026 conditions and Trump approval as reasonable proxies, which will be updated as more 2028-specific data becomes available.

Limitations

  • Candidate favorability scores use polling-based estimates (not real-time favorability)
  • GDP growth uses placeholder values (FRED API integration pending)
  • Polling data may be limited for 2028 presidential race (early in cycle)
  • Historical backtest is limited to 2020 and 2016
  • Model assumes static candidate characteristics (no campaign effects)
  • Data sources may have rate limits or availability issues
