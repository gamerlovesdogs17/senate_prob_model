Sources

Use public feeds where they exist. Curate what is not public.

There is no single free source that cleanly powers a serious Senate forecast. The daily generator combines public feeds where reachable with a transparent manual ratings file.

Polling

VoteHub Polling API

Free beta REST API for approval, generic ballot, favorability, and available poll subjects. The generator checks it server-side during the daily run.

Open API docs
Finance

OpenFEC

Official public campaign-finance API for candidates, committees, receipts, spending, cash on hand, and filings.

Open API docs
History

MIT Election Lab

Statewide, county, precinct, and 2024 election returns for fundamentals, validation, and backtesting.

Open datasets
Demographics

Census API

Population and demographic variables for turnout context, electorate modeling, and state baselines.

Open guide
Live results

civicAPI

No-auth public election results API. Useful for live results and any available race/polling data, with attribution requirements.

Open docs
Map geometry

us-atlas

Public TopoJSON state geometry used by the site to render actual U.S. state shapes through D3.

Open package
Historical only

FiveThirtyEight archives

538 was shut down, so it should not be a live polling dependency. Archived data can still be useful for historical backtesting where available.

Manual ledger

Ratings and news

Cook, Sabato, Inside Elections, Split Ticket, CNalysis, retirements, scandals, endorsements, ballot access, primary results, and party-withdrawal/independent-control arrangements should be curated rather than scraped.

Not free core

AP, DDHQ, Cook API

These are useful professional feeds, but they are gated, commercial, or credentialed. Do not design the public prototype around hidden access.
